# Glossary quick-ref (Doc 09 canonical)

Use these terms exactly. Never paraphrase.

| Term | Definition (short) |
|---|---|
| **VIN** | Vehicle Identification Number — the 17-char global ID. Primary key on a vehicle. |
| **Outlet** | A physical store (Bangalore, Mumbai, Chennai). All rows are outlet-scoped by default. |
| **Consignor** | The owner of a vehicle on consignment (not outright purchase). |
| **Consignment** | A listing model where we sell on behalf of the owner for a fee. |
| **Outright Purchase** | We buy the vehicle onto our books before resale. |
| **Appraisal** | The structured inspection that produces a valuation and condition grade. |
| **Condition Grade** | A to E scale on cosmetic + mechanical + structural + service history. |
| **Refurb** | Work done on a vehicle before listing — bodywork, mechanical, detailing. |
| **Landed Cost** | Acquisition + all refurb + transport + detailing + floor-plan interest + listing costs. |
| **Per-VIN Cost Ledger** | Append-only ledger of every cost attributable to a VIN. |
| **Listing** | A published VIN with price, photos, narrative, location. |
| **Reservation** | A short-lived hold on a VIN by a customer with a refundable deposit. |
| **CPO** | Certified Pre-Owned — vehicle passed a 150+ point check with warranty. |
| **Buyback** | Customer trades in an old vehicle against a new or pre-owned purchase. |
| **Job Card** | The opened work order for a service visit. |
| **RO** | Repair Order — an invoice-ready job card with parts + labour. |
| **GRN** | Goods Receipt Note — warehouse record of parts inbound. |
| **GST Margin Scheme** | India tax scheme: GST paid on margin, not full value, for second-hand goods. |
| **TCS** | Tax Collected at Source — 1% on sales > ₹10L per PAN per FY. |
| **IRN** | Invoice Reference Number — assigned by the IRP to a valid e-invoice. |
| **IRP** | Invoice Registration Portal (GST network). |
| **QR Code** | E-invoice QR issued by the IRP; must appear on invoice PDF. |
| **DPDP Act** | Digital Personal Data Protection Act 2023. India data protection regime. |
| **DLT** | Distributed Ledger Technology — TRAI SMS template registry. |
| **BSP** | Business Solution Provider — WhatsApp API partner (Gupshup, AiSensy, MSG91, Wati). |
| **sub-KUA** | Sub-KYC User Agency — authorized Aadhaar eKYC intermediary. |
| **GL** | General Ledger — accounting book of accounts. |
| **Tally** | Tally Prime, the statutory accounting system of record. |
| **DMS** | Data Management System — this product. |
